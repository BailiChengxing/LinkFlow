## 🌟 核心功能

- 🧹 **智能文本清洗**：基于正则深度匹配，自动滤除文本中的中文字符、符号（如括号 `【】[]`）及无用尾标。
- 📋 **剪切板无缝读取**：内置便捷按钮，一键同步系统剪切板内容，无需手动 Ctrl+V。
- 🚀 **一键批量打开**：支持单条快速打开或直接批量跳转，极大提升日常操作效率。
- 🛡️ **安全且注重隐私**：基于纯原生 JS 开发，所有提取与清洗过程均在**本地浏览器执行**，零数据上传。
- 🎨 **极简卡片 UI**：精心设计的现代化极简界面，契合原生浏览器交互体验。
